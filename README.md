# Proyecto-Domotica

Landing page y documentos de **Nodo Domótica**, servicio de domótica para casas y pequeños negocios en Santiago.

- Sitio publicado: https://nodo-domotica.vercel.app
- `index.html`: la página (un solo archivo estático).
- `CONTEXTO-PROYECTO-NODO.md`: contexto completo del negocio (decisiones, planes, precios, pendientes).
- `PRODUCT.md` y `DESIGN.md`: ficha de producto y sistema de diseño.
- `redes/`: publicación e imagen para Facebook.
- `research_notes/`: notas de investigación de precios, competencia e importación.
- `subir-a-vercel.bat`: publica la página en Vercel.
